## 68 元买到的是什么：五个能立刻用上的功能

第一个是访达里的文件管理。手机的存储会挂到 Mac 访达，存储卡、相机目录都能打开，连根目录也给挂上。复制、移动、重命名、删除，操作手感和本地文件夹一样。

第二个是在 Mac 上跑安卓 App。基础玩法是投屏，整块手机画面搬到电脑上，用鼠标键盘操作；进阶是融合模式，每个安卓 App 单独开一个 Mac 窗口，有独立 Dock 图标和 Mac 菜单栏，深色浅色跟着 macOS 走，不跟手机走。融合模式下手机可以锁屏去干别的事，App 照样在 Mac 上开着。中文输入法、摄像头、麦克风、触控板调用的都是 Mac 的硬件。

第三个是通知和剪贴板同步。手机收到的验证码会直接弹在 macOS 通知中心，不用低头看手机；文本和图片双向复制粘贴，微信里传文件费劲的问题也一起解决了。

第四个是 AI Agent 操控手机。AndroMeld 内置了 MCP 服务器，配一个 OpenClaw 之类的 Agent，把软件给出的提示词发过去，它自己完成配置，之后你用自然语言下指令，它在手机上点开浏览器、搜索、把结果回给你。想试手机自动化又不想写代码的人，这条路最省事。

第五个是连接方式。USB 有线走高速，官方说 300G 以上的照片视频目录遍历不卡，大文件传输建议用 USB 3.0 线；无线走 ADB 无线调试，手机和 Mac 连同一个 Wi-Fi 就行，还支持低功耗蓝牙一键开热点。

免费额度也值得说清楚：不付钱也能用全部功能，限制是每周可启动镜像 30 次、文件写入 5G、读取不限，额度每周重置。一周开三十次，平均一天四次多。偶尔传文件、隔三差五在电脑上回个手机消息的人，免费额度其实够用，不必急着买。
